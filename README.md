# All for One  

## Descrição breve  
Este projeto marca o início da minha jornada com backend e bancos de dados. Desenvolvido durante o curso, ele foi meu primeiro contato com MySQL, onde aprendi conceitos fundamentais como criação de tabelas, relações N:1, interação com banco de dados via JavaScript utilizando a metodologia CRUD e o uso de Docker Compose.  

## Como rodar o projeto  
1. Clone o repositório:  
   ```bash
   git clone https://github.com/Gzuuu/mysql-all-for-one-project.git
   ```  
2. Navegue para a pasta do projeto:  
   ```bash
   cd mysql-all-for-one-project
   ```  
3. Instale as dependências:  
   ```bash
   npm install
   ```  
4. Caso deseje, execute os testes:  
   ```bash
   npm test
   ```  

> **Nota:** Este é um projeto backend e não possui interface de usuário.  

## Tecnologias utilizadas  
- MySQL  
- Docker Compose  
- JavaScript  

## Principais aprendizados  
- Primeiros passos com bancos de dados utilizando MySQL.  
- Conceitos de modelagem de dados e relações N:1.  
- Interação backend-database utilizando JavaScript.  
- Utilização de Docker Compose para facilitar a configuração do ambiente.
